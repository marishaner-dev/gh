# Веб-визуализация ПЛК210

ПЛК210 отдаёт экран CODESYS WebVisu своим веб-сервером. После загрузки проекта страница открывается по адресу `http://<IP-ПЛК>:8080/webvisu.htm`. Порт меняется в веб-конфигураторе контроллера, HTTPS — порт 8443.

Панель СП307 и верхний уровень сюда не ходят: они читают Modbus, карта в `MODBUS.md`. Веб-экран пишет и читает переменные напрямую.

## Узел WebVisu

1. В дереве проекта добавить Visualization Manager, если его ещё нет.
2. Внутри него добавить объект WebVisu.
3. Стартовая визуализация — `Visu_Main`. Имя htm-файла — `webvisu`. Период обновления 200 мс.
4. Создать визуализацию `Visu_Main` и два списка текстов: `Text_Scheme`, `Text_Banner`.
5. Загрузить приложение в ПЛК210 вместе с визуализацией. Отдельный веб-сервер поднимать не нужно.

## Списки текстов

`Text_Scheme`, индекс — `GVL_Set.CoolingType`:

| ID | Текст |
| --- | --- |
| 1 | М/Д |
| 2 | М/Д1/Д2 |
| 3 | М/Д/ДЦ |
| 4 | М/Д1/Д2/ДЦ |

`Text_Banner`, индекс — `GVL_Visu.BannerCode`:

| ID | Текст |
| --- | --- |
| 0 | Норма |
| 1 | Сирена |
| 2 | Авария по маслу |
| 3 | Авария по обмотке |
| 4 | Предупреждение по маслу |
| 5 | Предупреждение по обмотке |
| 6 | Отказ датчика |
| 7 | Ошибка состава |
| 8 | Выключатель отключён |
| 9 | Ручной режим |

Код 1 в программе не выставляется: сирена — отдельная лампа `GVL_HMI.Horn`. Строка оставлена, если текст понадобится на другом экране.

## Экран Visu_Main

Поля ввода пишут сразу в `GVL_Set`. Эти переменные RETAIN PERSISTENT, после перезапуска ПЛК уставки сохраняются. Кнопки-импульсы пишут в `GVL_Visu` и сбрасываются программой в том же цикле. У кнопки в свойствах включить Tap.

| Элемент | Переменная |
| --- | --- |
| Текст схемы | `GVL_Set.CoolingType`, список `Text_Scheme` |
| Прямоугольник «ВСМ» | `GVL_HMI.Tm`, формат `%.1f` °C |
| Прямоугольник «НСМ» | `GVL_HMI.Tnsm` |
| Прямоугольник «ННТ» | `GVL_HMI.Tw` |
| Прямоугольник «Ток ВН» | `GVL_HMI.Current` |
| Прямоугольник «Нагрузка» | `GVL_HMI.LoadPercent` |
| Лампа Д1, Д2, ДЦ | `GVL_HMI.StageD1`, `StageD2`, `StageDC` |
| Лампы DO5…DO12 | `GVL_HMI.FanRun[1]` … `[8]`: два реле Д1, два Д2, четыре ДЦ |
| Лампа DO1 / DO2 | `GVL_HMI.CoolingOff`, `CoolingAlarm` |
| Лампа сирены | `GVL_HMI.Horn` |
| Лампы аварии и предупреждения | `GVL_HMI.AlarmOil`, `AlarmWinding`, `WarnOil`, `WarnWinding` |
| Текст состояния | `GVL_Visu.BannerCode`, список `Text_Banner` |
| Счётчик связи | `GVL_Visu.Heartbeat` |
| Кнопка «Квитировать» | `GVL_Visu.BtnAck` |
| Кнопка «Сбросить наработку» | `GVL_Visu.BtnResetHours` |
| Кнопка «Сбросить нагрев» | `GVL_Visu.BtnResetTheta` |
| Переключатель схемы | `GVL_Set.CoolingType`, значения 1…4 |
| Поля уставок ступеней, задержек, k21, k22, шкал 4…20 мА | одноимённые поля `GVL_Set` |
| Флажки ступеней, блокировок и ручного режима | `EnableD1`, `EnableD2`, `EnableDC`, `BlockPumps`, `BlockFans`, `Manual` |
| Ручной пуск реле i | `GVL_Set.ManualFan[i]`, работает при `Manual` или когда снят `DI_Auto` |

Имитацию `Simulation`, `SimTm`, `SimCurrent` на обычный экран не выводить. Она нужна для наладки без датчиков и включается с панели по Modbus.
