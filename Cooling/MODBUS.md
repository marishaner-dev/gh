# Modbus TCP для СП307-Б и верхнего уровня

Контроллер ПЛК210 — ведомое устройство. Порт 502, адрес узла 1. Holding-регистры (функции 3, 6 и 16) начинаются с нуля и лежат в массиве `MB`.

REAL занимает два регистра: **старшее слово по младшему адресу** (25.0 = `16#41C8`, `16#0000`). Проверка — регистры 90 и 91, там всегда 25.0. Если панель показывает другое число, запишите в бит 7 регистра флагов единицу (`SwapWords`): слова поменяются местами.

UDINT (число пусков) упакован так же: старшие 16 бит в первом регистре.

| 14 | INT | Тип СО: 1 М/Д, 2 М/Д1/Д2, 3 М/Д/ДЦ, 4 М/Д1/Д2/ДЦ |

| 16 | WORD | Слово сигнализации |

| Бит | Смысл |
| --- | --- |
| 0 | Отказ датчика верхнего масла |
| 1 | Отказ датчика тока |
| 2 | Отказ датчика нижнего масла |
| 3 | Трансформатор в работе |
| 4 | Аварийное включение охлаждения |
| 5 | Сирена |

| 8 | Ступень Д1 |
| 9 | Ступень Д2 |
| 10 | Ступень ДЦ |

| 13 | DO2, охлаждение неисправно |

Биты регистра 16: 0 предупреждение по маслу, 1 авария по маслу, 2 предупреждение по обмотке, 3 авария по обмотке, 4 нет подтверждения от вентилятора.

Биты регистра 87: 1 номинальный ток не задан, 2 отрицательный градиент. Уставки ступеней, задержки и константы ННТ лежат в `GVL_Set` и правятся с WebVisu. Буфер 101…127 по-прежнему задаёт тип, градиент, номинальный ток и шкалы.

## Запись уставок

Область 100…127 контроллер сам не перезаписывает, кроме регистра 100: после исполнения команды он обнуляется. Уставки применяются только целиком, по стробу, чтобы недописанный экран не попал в работу.

| Адрес | Тип | Смысл |
| --- | --- | --- |
| 100 | WORD | Команда: 1 записать уставки, 2 квитировать сирену, 3 сбросить наработку, 4 сбросить нагрев обмотки |
| 101 | WORD | Тип СО 1…4 |
| 102 | REAL | Градиент Gr, К |
| 104 | REAL | Номинальный ток In, А |
| 106 | WORD | Число вентиляторов |
| 107 | WORD | Число насосов |
| 108 | WORD | Число охладителей |
| 109 | REAL | Часов до смены охладителя, 0 — ротация выключена |
| 111 | REAL | Температура масла при 4 мА |
| 113 | REAL | Температура масла при 20 мА |
| 115 | REAL | Ток при 20 мА, А |
| 117 | WORD | Флаги |
| 118 | REAL | Имитация Tm, °C |
| 120 | REAL | Имитация тока, А |
| 122 | WORD | Ручной пуск вентиляторов, бит на двигатель |
| 123 | WORD | Ручной пуск насосов |
| 124 | REAL | Показатель Y, по листу 1,2 |
| 126 | REAL | Постоянная нагрева обмотки, с, по листу 480 |

Биты регистра 117: 0 нужен сигнал выключателя, 1 группы по таблице 4, 2 насосы 1-й группы на холостом ходу, 3 учитывать тепловые реле, 4 имитация, 5 ручной режим, 6 канал аналога уже в мА (иначе 0…100 %), 7 переставить слова REAL.

На СП307 экран уставок по кнопке «Записать» делает одну функцию 16 на регистры 101…127 и следом (или в том же запросе) пишет 1 в регистр 100. Квитирование — запись 2 в регистр 100, сброс наработки — 3, сброс нагрева обмотки — 4.

## Действующие уставки и причины пуска

Эту область программа заполняет каждый цикл. Её читают и панель, и верхний уровень. Писать сюда незачем: следующий цикл затрёт значение. Расклад 128…154 повторяет буфер 101…127, но это уже принятые уставки, а не черновик экрана.

| Адрес | Тип | Смысл |
| --- | --- | --- |
| 128 | WORD | Принятый тип СО |
| 129 | REAL | Градиент Gr, К |
| 131 | REAL | Номинальный ток In, А |
| 133 | WORD | Число вентиляторов |
| 134 | WORD | Число насосов |
| 135 | WORD | Число охладителей |
| 136 | REAL | Часов до смены охладителя |
| 138 | REAL | Масло при 4 мА |
| 140 | REAL | Масло при 20 мА |
| 142 | REAL | Ток при 20 мА, А |
| 144 | WORD | Флаги, те же биты, что у регистра 117 |
| 145 | REAL | Имитация Tm |
| 147 | REAL | Имитация тока |
| 149 | WORD | Ручной пуск вентиляторов |
| 150 | WORD | Ручной пуск насосов |
| 151 | REAL | Показатель Y |
| 153 | REAL | Постоянная нагрева, с |
| 160…167 | WORD | Причина пуска вентилятора 1…8, биты `R_*` из `GVL_Const` |
| 168…171 | WORD | Причина пуска насоса 1…4 |

## Кто с кем говорит

Один ведомый Modbus TCP, порт 502, узел 1, массив `MB`.

| Клиент | Что делает |
| --- | --- |
| Браузер, WebVisu `http://<IP ПЛК>:8080/webvisu.htm` | Читает и пишет переменные `GVL_HMI`, `GVL_Set`, кнопки `GVL_Visu`. Modbus ему не нужен. Сборка экрана — `plc/WEBVISU.md` |
| Панель СП307 | Читает 0…91 и 128…171. Пишет уставки в 101…127 и стробит регистр 100 |
| Верхний уровень | Читает 0…91 и 128…171 функцией 3. Регистр 19 — признак, что задача жива. Команды 100…127 верхнему уровню не нужны: управление остаётся у панели и веб-экрана |
