Охлаждение трансформатора
ОВЕН ПЛК210-04-CS, CODESYS V3.5, язык ST

Это не программа АВМ-КОТ и не ТМТ3. Экран и ступени сделаны по их образцу,
контроллер другой: ПЛК210-04-CS из пакета ОВЕН, не CODESYS Control Win.
Верхний уровень — Modbus TCP этого ПЛК, не IEC 60870 того прибора.

Перед загрузкой:
- FDI1…FDI12 — режим «определение логического уровня»
- DO1…DO12 — «переключение логического состояния»
- AI1, AI2, AI3 — «Ток 4…20 мА», в программу приходит 0…100 %
- AI4 выключить: опрос входов последовательный, до 0,6 с на канал
- тумблер СТАРТ/СТОП на лицевой панели — в положении СТАРТ
- Ethernet порты 1–3, заводской адрес 192.168.0.10
- Modbus TCP порт 502, WebVisu только в сети шкафа: http://192.168.0.10:8080/webvisu.htm

Клеммы по таблице привязки:
  AI1  AI_Tvsm     верхние слои масла
  AI2  AI_Tnsm     нижние слои масла
  AI3  AI_I        ток стороны ВН
  FDI1 DI_Auto    автоматический режим
  FDI2 DI_TransOn трансформатор в работе
  FDI3, FDI4      резерв
  FDI5…FDI12      вентиляторы 1…8 включены
  DO1  охлаждение отключено
  DO2  охлаждение неисправно
  DO3, DO4        резерв
  DO5, DO6        ступень Д1
  DO7, DO8        ступень Д2
  DO9…DO12        ступень ДЦ

Пока FDI5…FDI12 не смонтированы, UseFanFeedback = FALSE.
Память уставок и нагрева — RETAIN PERSISTENT, MRAM 64 Кбайт.
Библиотека Standard нужна для EXPT, SEL, LIMIT, SHL.
